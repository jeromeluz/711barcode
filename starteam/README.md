# 造勢物品管理系統｜盤點重新計算剩餘數量

部署：將 `index.html`、`app.js`、`firebase-config.js`、`.nojekyll` 上傳至 GitHub Pages 的 `starteam/` 目錄。不要重新匯入 `initial-database.json`，以免覆蓋正式資料。

## 盤點規則

- 應有總數 = 良品 + 損壞品。
- 尚未歸還 = 該門市該物品所有取用紀錄數量合計 − 歸還紀錄數量合計，最小為 0。
- 盤點後剩餘數量 = 新的應有總數 − 尚未歸還。
- 可借用良品 = min(剩餘數量, 良品數量 − 尚未歸還)，最小為 0。
- 若尚未歸還超過新的應有總數，盤點會拒絕寫入，請先核對歷史紀錄。
- 每筆盤點紀錄保存盤點前後應有、好壞、剩餘及未歸還數量。

**重要：** 本版本依靠 Firebase `inventory/history` 中完整的取用及歸還紀錄來計算尚未歸還。如果早期借用沒有登記、紀錄曾被刪除，或過去歸還紀錄超過取用紀錄，無法從歷史精確還原借用狀態。請先備份 Firebase 並核對借出未歸還數量，再進行第一次盤點。

本系統使用公開讀寫規則，請注意定期備份與公開存取風險。


## 好壞狀態與借用
損壞品更名為「損壞/舊品」。此類物品仍計入應有總數與剩餘庫存，也允許借用。可借用數量以剩餘數量為準，不因標記為損壞/舊品而扣除。盤點仍以良品 + 損壞/舊品 = 應有總數，並依尚未歸還紀錄重算剩餘數量。
